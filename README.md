# 黑猪数学（Heizhu Shuxue）

写给家长的小学数学长文讲义。11 篇，11.3 万汉字，116 张自绘配图。

孩子会写 3456，不等于懂 3456。你指着 `3456` 问一句「这里的 3 和 4，哪个大」，
他多半脱口而出「4 大呀」。在 3456 里 3 表示三千、4 表示四百，**3 比 4 大得多**。
这不是粗心，也不是没背熟：在他心里 3456 还是四个符号排成一队，不是一组有权重的量。

这套讲义就是从这个位置开始写的。每一讲不教怎么做题，回答四件事：
这个坎为什么重要、孩子到底错在哪、今晚在家里能做一个什么动作、到什么时候可以放手。

![位值制](小学/01_位值制/图0_封面.png)

## 这是什么

- **写给家长，不是给孩子刷的习题册。** 读者是小学阶段孩子的家长，场景是陪写作业和看卷子。
- **每讲一篇长文**，9,000 到 16,000 汉字，一篇只讲一个坎，不按教材章节切。
- **判断优先于方法。** 市面上给方法（多刷题、错题本、提前学），这里给判断：
  这个错要不要管、管到什么程度、什么时候能停、还要多久。
- **全部是纯文本与图片。** Markdown 讲义加同目录 PNG，没有构建步骤，不依赖任何服务，
  克隆下来用任意编辑器或 GitHub 页面就能读。

## 怎么读

- **只想看全局**：先读第 10 讲《思想地图》，它把六年的等号拆成九站，能直接判断孩子卡在哪一站。
- **顺着读**：01 到 10 是一条线，位值制 → 四则运算 → 运算律 → 分数 → 代数 → 质数 → 比例 → 几何 → 统计。
- **单篇独立**：每篇自带导读与背景，跳读不会断。
- 每篇开头都有导读，写明读完全文能拿到哪几样东西，以及时间紧的话先读哪一节。

## 一篇的结构

导读 → 正文若干节 → 典型错题解剖 → 给家长的分寸 → 思想远征 → 结语 → 参考文献 → 互动。

- **典型错题解剖**：一个错分三层写，症状、病灶、根治。三个错不重复。
- **给家长的分寸**：三该做三不该做，只写行为不写道理。
- **思想远征**：这一段往后通到哪，标注了这是大学的，娃不需要懂。
- 第 10 讲体例不同：按九站铺，每站固定五样（学到哪儿、等号在这一站的新意思、这一站想的是什么、娃常卡在哪、家长能做的）。

## 配图怎么来的

全部用 matplotlib 代码绘制，不是用 AI 生图，也不是素材图。每张图的脚本都在写作过程中现写，
图里的算式、刻度、数字都验过。画法上的一条硬规矩：图只承担一件事，相邻两张不讲同一件事。

这么做的好处是图能改，正文改了图跟着改；坏处是初期很慢，一张图要调版式。取舍选前者。

## 边界

- **不替代教材**，也不按教材章节逐节讲。教材在这里是被评价的对象，不是讲解的坐标。
- **不含习题与答案**，这是讲义不是练习册。
- 年级与学段按 2022 版课程标准自查过（例如「概率」这个词小学不用，只说「可能性」），
  但不提供教材版本对照表。
- 文中引用的史料、人名与年代都核过出处；追不到原文的材料宁可不写。
- 写的是作者自己的判断，欢迎指出错误，但不同意某个判断请说理由。
